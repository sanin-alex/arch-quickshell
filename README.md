# Simple Quickshell Bar
A simple Taskbar for hyprland, made with quickshell.
<img width="1920" height="40" alt="image" src="https://github.com/user-attachments/assets/2b220f3b-e4a9-4422-87b5-ff12af130543" />
Shows:
- Hyprland workspaces
- Date & Time
- Battery capacity and status

### Install & Run
Before installing and running make sure to install the quickshell package.<br />
For Arch: `pacman -S quickshell`<br />
`git clone https://github.com/sanin-alex/arch-quickshell`<br />
`cd arch-quickshell`<br />
`qs -p shell.qml`
